Frequently Asked Questions

Straight answers about domain records, WHOIS, RDAP, DNS, privacy and how the lookup works.

What is RDAP?

RDAP (Registration Data Access Protocol) is the modern standard that replaces WHOIS. It returns structured JSON over HTTPS, supports secure connections, and is run by every major registry including .com, .net, .org and .in. DomainLookup queries RDAP first and falls back to WHOIS only when needed.

What is the difference between WHOIS and RDAP?

WHOIS is a plain-text format that varies from registry to registry — the same field can have a different name on every server. RDAP is structured JSON, so tools can read it reliably. DomainLookup shows both when they are available, and you can switch to the raw view in the results tab.

Is the domain data live?

Yes. Every search asks the registry directly through RDAP and, where available, the WHOIS server. Results are cached for about 60 seconds so repeated searches are fast and fair to the registries.

Why can't I see the domain owner?

Since 2018, most registrars hide personal contact details by default under GDPR and similar privacy laws. DomainLookup only shows what the registry publishes and never guesses an owner. If you need to contact an owner, some registrars offer an anonymous contact form.

What does "available" mean here?

The registry reported no record for that name. Some registries answer the same way for reserved or blocked names, so confirm with a registrar before you buy. Premium and auction names may also show as available but carry a higher price.

Can I check other extensions of the same name?

Yes. Every result includes a list of other extensions (.com, .net, .org, .in, .co, .io, .info, .co.in) with their status. Click one to open its full record. This is useful when you are choosing between TLDs for a new project.

Can I look up an IP address or a URL?

You can paste a full URL and we extract the domain. IP addresses are not supported because they use a different registry system (RIRs — Regional Internet Registries) with their own RDAP services.

What are DNS records and why do they matter?

DNS records tell the internet how to reach your domain. A and AAAA records map to IPv4 and IPv6 addresses, MX handles email delivery, NS points to the authoritative nameservers, TXT holds verification and SPF/DKIM data, CNAME aliases one name to another, SOA defines the zone authority and CAA restricts which certificate authorities can issue SSL certificates for your domain.

How does DomainLookup fetch DNS records?

We query public DNS-over-HTTPS (DoH) resolvers — Cloudflare (1.1.1.1) and Google (8.8.8.8) — directly from your browser. No backend is involved, and no DNS query is logged against your account.

Why did my lookup fail?

Common causes: a typo, a registry that is temporarily down or rate limiting you, or an extension that has no public RDAP service. The error message says which one. Try again in a minute if it is a rate-limit issue.

What do the status codes mean?

They describe locks and holds. For example, "clientTransferProhibited" means the registrar has locked the domain against transfers. "clientHold" means DNS resolution is suspended. We explain each one in plain language next to the code in your results.

Do you store my searches or personal data?

No accounts, no cookies, no analytics and no search history. The server keeps a short-lived cache (about 60 seconds) and a per-minute request counter in memory only — nothing is written to disk. Full details are in the privacy policy.

Is there a limit on searches?

Yes — a fair-use limit per minute per visitor, to protect the public registry services from overload. The limit is generous for normal use and only kicks in with automated bulk queries.

Can I use DomainLookup for bulk lookups or an API?

The public site is for individual lookups. If you need bulk lookups or an API for your own product, contact Access Authority to discuss access.
